# 彩票大师 (Lottery Master) Android 应用

专为手机端全新重新设计的双色球 (SSQ)、大乐透 (DLT)、快乐8 (KL8) 移动端深度分析、历史记录检索与预测比对系统。

---

## 🌟 核心特色与功能模块

### 1. 📜 全彩种历史开奖数据列表 (`HistoryScreen`)
- **对齐 Web 端 `/ssq/history`、`/dlt/history`、`/kl8/history`**。
- **手机专属卡片流式设计**：彻底告别宽表格横向拖动，以紧凑轻量卡片呈现双色球、大乐透、快乐8各 2000+ 期历史开奖数据。
- **全维度指标一览**：每期清楚展示期号、开奖日期、红球蓝球高光球体、和值、跨度、奇偶比、最大遗漏、出奖地区等。
- **实时搜索与筛选**：支持输入期号或年份关键词秒级过滤。
- **与分析看板一键联动**：点击历史列表中的任意期次，立即切换至该期并跳转到【分析看板】查看全量深度遗漏与形态分析。

### 2. 🔮 预测比对与心水红球工具箱 (`PredictCompareScreen`)
- **❤️ 心水红球自选工作台**：
  - 针对双色球（1-33）、大乐透（1-35）、快乐8（1-80）提供全盘交互点选球号网格；
  - 支持手动输入框批量输入、清空自选、一键随机机选；
  - 选中的心水号码在预测分组中自动**涂红并带金色光圈高亮**。
- **📋 他人红球频次收集与比对**：
  - 支持粘贴别人购买或专家推荐的号码（自动支持连续无空格数字 2 位切割、多行识别）；
  - 自动统计各号码出现热度频次与注数，展示最高频次排行榜；
  - 在下期预测遗漏分组中，对应的球右上角自动标注**紫色热度角标 (如 `x3`、`x5`)**。
- **🎯 遗漏层级穿透透视分析**：
  - 实时分析心水号码在当前下期 0~9+ 遗漏层级中的分布分布（如：重号0层 2码，热号1层 1码，冷号9+层 1码），科学把控选号冷热结构。

### 3. 📊 深度走势综合看板 (`LotteryDashboardScreen`)
- **开奖号码高光展示**：双色球（6红1蓝）、大乐透（5红2蓝）、快乐8（20个橙金球），右上角动态标出当期开出遗漏值。
- **形态指标网格**：和值、跨度、奇偶比、三区/四区比、连号、同尾号、最大遗漏、遗漏总和。
- **下期遗漏分组预测 (参考池)**：纯 Kotlin 移植的高性能计算引擎，模拟下期 0~9+ 层级的号码池。
- **开出号码遗漏详情与冷热判定**：标注【热】(≤4期)、【温】(5-9期)、【冷】(≥10期)。
- **全盘冷热温号分布雷达**。

### 4. 📈 走势与模拟工具箱 (`ToolsScreen`)
- **单号遗漏起伏折线走势图**：使用 Compose Canvas 动态绘制任意号码近期 20+ 期的遗漏起伏曲线。
- **黄金比例智能模拟组号**：依据冷温热黄金比例（3热 + 2温 + 1冷）智能模拟推荐选号。

## 🚀 如何在 Android Studio 中打开与运行

1. 打开 **Android Studio** (推荐 Hedgehog 2023.1.1 或更高版本)；
2. 点击 **Open**，选择路径 `E:\Project\lottery\android`；
3. 等待 Gradle 自动完成依赖同步 (Sync)；
4. 连接 Android 手机或启动模拟器 (Android 8.0 / API 26+)，点击 **Run 'app'** 即可在真机上体验！
